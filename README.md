# Tetris

A simple Tetris game in one HTML file. Open `index.html` in a browser to play.

## Controls

**Computer:** ← → move, ↑ rotate, ↓ soft drop, space hard drop, P pause.

**Phone:** tap to rotate, drag sideways to move, drag down to soft drop, flick down to hard drop.

## Block colours

From the Pantone palette: Transparent Yellow `#F5EFC6`, Sceptre Red `#4D0E12`, Cerulean `#A5BCD6`, Potting Soil `#4A2E27`, Java `#231815`.
Added to match it: dusty blue `#6E86A6`, raspberry `#9C3D48`.

The rest of the site is black and white, set in Helvetica Neue.
