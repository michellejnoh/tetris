# Tetris

A simple Tetris game in one HTML file. Open `index.html` in a browser to play.

Controls: ← → move, ↑ rotate, ↓ soft drop, space hard drop, P pause. On a phone, use the on-screen buttons.

Colour palette (Pantone): Transparent Yellow `#F5EFC6`, Sceptre Red `#4D0E12`, Cerulean `#A5BCD6`, Potting Soil `#4A2E27`, Java `#231815`.
